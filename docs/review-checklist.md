# Review Checklist

## Scope

- [ ] Change type correct
- [ ] Requirement clear
- [ ] Impact plan matches diff
- [ ] No unrelated changes

## Correctness

- [ ] Acceptance criteria met
- [ ] Edge cases covered
- [ ] Error paths handled
- [ ] Tests/evidence credible

## API/business logic

- [ ] Contract compatibility checked
- [ ] Business rule source cited
- [ ] Auth/permission impact checked
- [ ] Data migration/rollback considered

## Quality

- [ ] Code is simple and maintainable
- [ ] Names and patterns match repo
- [ ] No duplicated logic without reason
- [ ] Observability/security/performance considered when relevant

## Merge readiness

- [ ] CI/validation pass
- [ ] Rollback plan present
- [ ] Remaining risks explicit
