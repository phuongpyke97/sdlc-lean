# Security Checklist

Use for API, auth, data, dependency, file upload, external integration, or business-critical changes.

- [ ] AuthN/AuthZ checked
- [ ] Input validation checked
- [ ] Output/data exposure checked
- [ ] Secrets not logged or committed
- [ ] Sensitive data handling reviewed
- [ ] Rate limit/abuse cases considered
- [ ] Dependency risk considered
- [ ] Error messages do not leak internals
- [ ] Audit/logging needs considered
- [ ] Security reviewer consulted when high risk
