# Small Change Flow

Small changes should stay lightweight but still traceable.

1. Confirm the change is low risk.
2. Search only the local affected area unless shared behavior is touched.
3. Write a short impact note.
4. Get lightweight approval if code behavior changes.
5. Make the edit.
6. Run smoke validation.
7. Report result.

## Examples

- copy/docs update
- small config rename
- isolated validation tweak
- non-breaking API description update

Escalate to another flow if risk expands.
