# Observability Checklist

Use when a change affects production behavior, APIs, jobs, integrations, or business-critical flows.

- [ ] Logs include useful context without sensitive data
- [ ] Errors are visible and actionable
- [ ] Metrics exist for success/failure/latency where relevant
- [ ] Traces/spans considered for distributed flows
- [ ] Alert impact considered
- [ ] Dashboards/runbooks updated if needed
- [ ] Rollback can be detected and verified
