# Bugfix Flow

1. Capture observed behavior.
2. Capture expected behavior.
3. Reproduce or document why reproduction is not possible.
4. Search related code/tests with Graphify.
5. Identify root cause.
6. Create impact plan.
7. Get approval.
8. Fix narrowly.
9. Add regression test or equivalent evidence.
10. Report before/after result.

## Required evidence

- reproduction steps/logs
- root cause
- regression test or manual verification
- affected files
