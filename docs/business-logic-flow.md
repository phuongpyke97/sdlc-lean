# Business Logic Flow

1. Identify source of truth for rule.
2. Capture examples and edge cases.
3. Search affected code/tests with Graphify.
4. Create impact plan.
5. Get business/product approval.
6. Implement with readable rule names.
7. Add tests for examples and edge cases.
8. Report rule evidence and remaining ambiguity.

## Required evidence

- rule source
- before/after examples
- edge cases
- product/business approval
