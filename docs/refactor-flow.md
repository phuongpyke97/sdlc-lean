# Refactor Flow

1. State intended behavior preservation.
2. Search related code/tests with Graphify.
3. Identify modules and coupling.
4. Create impact plan.
5. Get approval if non-trivial.
6. Refactor in small steps.
7. Run existing tests/build.
8. Report no-behavior-change evidence.

## Guardrails

- Do not mix feature work with refactor.
- Do not change API/business behavior unless reclassified.
- Prefer mechanical, reviewable changes.
