# Ownership

## Roles

- Developer: implements, tests, reports evidence.
- Reviewer: validates correctness, maintainability, evidence.
- Tech Lead: owns architecture/risk decisions.
- Product/Business Owner: owns requirements and business rules.
- Security Owner: owns security-sensitive approval.
- Release Owner: owns rollout/rollback.

## Ownership rules

- Each PR has one responsible developer.
- Each high-risk PR has an accountable approver.
- Business logic changes need business owner confirmation.
- API breaking changes need consumer impact review.
