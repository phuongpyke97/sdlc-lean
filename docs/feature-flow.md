# Feature Flow

1. Capture requirement brief.
2. Define acceptance criteria and non-goals.
3. Search related code with Graphify.
4. Create impact plan.
5. Assess risk and approvals.
6. Get approval.
7. Implement in small slices.
8. Add/update tests.
9. Run build/validation.
10. Report evidence in PR.

## Required evidence

- acceptance criteria result
- tests run
- build/validation status
- rollout/rollback note
