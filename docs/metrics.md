# Metrics

Use metrics to improve workflow, not punish teams.

## Delivery metrics

- cycle time: request approved → merged
- lead time: request created → merged
- review latency: PR opened → first review
- rework rate: PR comments requiring implementation changes

## Quality metrics

- escaped defects
- flaky test rate
- rollback count
- reopened bugs
- high-risk changes without evidence

## Adoption metrics

- PRs with complete impact plan
- PRs with test evidence
- skipped checks count
- approval policy compliance

Review monthly. Improve one bottleneck at a time.
